# Vectorization evidence (concise)

Generated by `scripts/vec_evidence.py` from the compiler reports (GCC `-fopt-info-vec-all`, Clang `-Rpass*=loop-vectorize`) and `objdump -d` of each kernel. Each case shows the compiler's verdict on the kernel's main loop and that loop's instructions (truncated to 15). Every build x dtype x kernel is in `status_matrix.csv`; `tests/test_vectorization.py` asserts that report and disassembly agree for all of them.
